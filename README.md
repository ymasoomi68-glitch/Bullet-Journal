# دفتر برنامه روزانه (Bullet Journal)

یک برنامهٔ وب نصب‌شدنی (PWA) برای ثبت کارهای روزانه، با گزارش هفتگی، ماهانه و سالانه.

## امکانات

- چک‌لیست روزانهٔ ۱۰ کار (تیک‌زدن با یک لمس) و امکان ثبت یا اصلاح روزهای گذشته
- تقویم شمسی، شروع هفته از شنبه، ارقام فارسی
- گزارش هفتگی (جدول کامل کارها × روزها)، ماهانه (تقویم رنگی) و سالانه (نمودار ماه‌ها)
- برای هر کار مشخص است در کدام روزها انجام شده و در کدام روزها انجام نشده
- ذخیرهٔ دائمی اطلاعات روی دستگاه با **localForage (IndexedDB)**
- دکمهٔ «نصب روی این دستگاه» و دکمهٔ «به‌روزرسانی»
- کار کردن بدون اینترنت (آفلاین)
- پشتیبان‌گیری و بازیابی اطلاعات (در بخش تنظیمات)
- افزودن، ویرایش و حذف کارهای روزانه (سابقهٔ کارهای حذف‌شده در گزارش‌ها می‌ماند)
- انتخاب اندازهٔ نوشته‌ها (کوچک تا خیلی بزرگ)
- حالت روشن و تیره (خودکار، مطابق تنظیم گوشی)

## انتشار روی GitHub Pages

1. همهٔ فایل‌های این پوشه را (نه خودِ پوشه را) در مخزن `ymasoomi68-glitch/Bullet-Journal` آپلود کن؛ فایل `index.html` باید در ریشهٔ مخزن باشد.
2. در مخزن به **Settings ← Pages** برو.
3. در بخش **Build and deployment** گزینهٔ **Deploy from a branch** را بزن، شاخهٔ **main** و پوشهٔ **/ (root)** را انتخاب کن و **Save** بزن.
4. بعد از یکی دو دقیقه برنامه در این نشانی باز می‌شود:

   `https://ymasoomi68-glitch.github.io/Bullet-Journal/`

## نصب روی گوشی

- **اندروید (Chrome):** نشانی بالا را باز کن و دکمهٔ «نصب روی این دستگاه» را بزن.
- **آیفون (Safari):** دکمهٔ اشتراک‌گذاری ← «Add to Home Screen».

## انتشار نسخهٔ جدید

1. بعد از هر تغییر در فایل‌ها، در `sw.js` عدد `VERSION` را عوض کن (مثلاً از `1.0.0` به `1.0.1`).
2. فایل‌ها را دوباره در گیت‌هاب آپلود کن.
3. در برنامه روی دکمهٔ «به‌روزرسانی» بزن تا نسخهٔ جدید نصب شود. (اطلاعات ثبت‌شده حفظ می‌شود.)

## ساختار فایل‌ها

| فایل | کاربرد |
| --- | --- |
| `index.html` | صفحهٔ اصلی |
| `style.css` | ظاهر برنامه |
| `app.js` | منطق برنامه (چک‌لیست، گزارش‌ها، نصب، به‌روزرسانی) |
| `jalali.js` | تبدیل تاریخ میلادی و شمسی |
| `sw.js` | سرویس‌ورکر (حالت آفلاین و به‌روزرسانی) |
| `manifest.webmanifest` | مشخصات نصب برنامه |
| `localforage.min.js` | کتابخانهٔ ذخیره‌سازی |
| `fonts/Vazirmatn.woff2` | فونت وزیرمتن |
| `icons/` | آیکن‌های برنامه |

## تغییر فهرست کارها

کارها از بخش «تنظیمات ← کارهای روزانه» اضافه، ویرایش و حذف می‌شوند و در خود برنامه ذخیره می‌شوند. فهرست اولیه (فقط برای اولین اجرا) در `DEFAULT_TASKS` ابتدای `app.js` است.
